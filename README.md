# HanziTrail

Story-based Mandarin flashcard app for learning technical vocabulary.

## Goal

HanziTrail helps learners remember Mandarin characters through:

- character stories
- pinyin
- meanings
- technical usage examples
- spaced repetition

## Stack

- Ruby on Rails
- Hotwire
- Bulma
- PostgreSQL
- Minitest
